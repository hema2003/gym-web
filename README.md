# جيم — متابعة التمرين

تطبيق ويب (PWA) بسيط تسجّل عليه تمارينك وأوزانك ووجباتك وتتابع تقدمك. بيشتغل من غير نت، والبيانات محفوظة على التلفون.

## التشغيل على التلفون
1. من GitHub: Settings → Pages → Source: `Deploy from a branch` → اختار الفرع و `/ (root)`.
2. افتح اللينك من Chrome على التلفون → القائمة ⋮ → **Add to Home screen / تثبيت التطبيق**.
3. لو عايز ملف APK: حط اللينك في https://www.pwabuilder.com واختار Android.
